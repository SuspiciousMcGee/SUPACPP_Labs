Readme file for assignment 1.

files used: AnalyseData.cxx, CustomFunctions.h, CustomFunctions.cxx

compilation: g++ -o AnalyseData AnalyseData.cxx CustomFunctions.cxx

User is prompted to choose options 1 through 5.

Option 1: print N(user input) lines of the data 

Option 2: calculate and print magnitude of each data point and print all --> output file magnitudes.txt 

Option 3: Least squares fit -- return fitted line plus chi2/ndof --> output file linear_fit.txt 

Option 4: calculate x^y values for all data points recursively and print results --> output file xPOWy_values.txt 

Option 5: Exit.
